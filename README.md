# Secure-File-Sharing
AES-256 Encrypted File Sharing App
Encryption part was managed by this user of this related app.

Extract the project:
cd secure-file-sharing
Create a virtual environment (recommended):

python -m venv venv
venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt
Run the application:
python app.py
Open in browser:
http://localhost:5000
